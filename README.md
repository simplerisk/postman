# SimpleRisk Postman Collection

Auto-published Postman collections for the SimpleRisk v2 API, generated from the
OpenAPI annotations by the `postman-collection` workflow in the SimpleRisk code
repository and committed here on each release.

## Branches

- **`master`** — the collection for the current **GA** (released) version.
- **`testing`** — the collection for the current **release candidate** (RC).

## Files

Each release's collection is published as
`SimpleRisk-<version>.postman_collection.json`
(for example `SimpleRisk-20260519-001.postman_collection.json`), where
`<version>` is the SimpleRisk release version. Re-generating the same version
overwrites that file.

Import the JSON into Postman (**File → Import**) to explore and call the
SimpleRisk API.
